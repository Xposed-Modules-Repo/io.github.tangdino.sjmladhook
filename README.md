# SJML AdHook（联掌门户精简）

非联掌官方的 LSPosed/Xposed 模块，仅作用于 com.fxicrazy.sjml。

## 功能
- 拦截六个业务广告服务中已识别的展示方法；保留 SDK 初始化，触发失败回调。
- 隐藏已识别的首页信息流和天幕悬浮广告容器。
- 隐藏首页京东等商业入口整栏及联掌商城推荐商品，保留物业服务。
- 从主页适配器移除服务页：五页变四页，并映射其余标签的实际页码。

## 使用
Android 8.0+，需要支持传统 Xposed API 82 的框架。安装模块后在 LSPosed 启用，仅勾选联掌门户，然后强制停止目标应用并重新打开。

## 验证与限制
分析基线：联掌门户4.11.1（202509250）。运行日志已确认信息流和悬浮广告拦截、服务页5→4、开门/我的页码映射。未全面验证所有机型、版本、广告投放及登录/深链接组合，不保证全部广告去除。不模拟广告观看或发放奖励，不改变门锁认证协议。任何误伤可通过禁用模块恢复。
